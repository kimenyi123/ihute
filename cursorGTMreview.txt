GO LIVE DECISION
----------------

NOT READY for a reliable money-critical launch without addressing backend coupling, secrets, and High gaps below. Limited pilot is possible if Java + Redis + env are stable and manual workarounds are accepted (e.g. phone copy-paste instead of Call button).

---

TOP 5 BLOCKERS
--------------

1. Backend dependency: Orders and catalog depend on Java + DB; Next.js only proxies — no guarantee "works every time" without ops monitoring.

2. supplier/add-product hardcoded DB credentials (localhost, fixed user/pass in app/api/supplier/add-product/route.ts) — security and deployment blocker.

3. Order ID fallback (ORD-${Date.now()}) when Java response is ambiguous — risk of false success for customers.

4. Real-time seller feed requires Redis; without it, live stream degrades (NO_REDIS).

5. typescript.ignoreBuildErrors: true — ships despite type errors; increases production risk.

---

FASTEST PATH TO MARKET (1 WEEK PLAN)
------------------------------------

1. Freeze env: Document NEXT_PUBLIC_API_URL, JAVA_* URLs, Redis URL; smoke-test /api/orders/create GET health and POST from staging.

2. Remove or gate add-product local MySQL route — point product creation to one Java/API path with env-based config only.

3. Supplier orders list: add tel: (and optional WhatsApp) using buyer phone from mapped order fields.

4. Order success: only redirect when json.ok && json.orderId matches backend contract; remove or narrow fallback ID.

5. CI: next build without ignoreBuildErrors, or fix top TS errors; run one E2E path: shop-with-me → cart → anonymous checkout → order-success.

6. Pilot checklist: Redis on for seller live stream OR enable polling fallback; verify seller registration end-to-end on staging Java.

---

FINAL NOTE
----------

Goal: a system that works every time for a simple shop and a simple customer. The code supports that path (anonymous checkout, Next API proxy, shop-with-me, order success). Reliability "every time" is not proven in-repo; it requires stable Java + DB + Redis + correct env and the fixes above.
